# Grantly – Unified Scholarship Management Platform

Grantly is a student-focused platform that helps students discover, explore, compare, and manage scholarship opportunities in one place.

## ✨ Features

- **Scholarship Explorer:** Browse and search available scholarships.
- **Eligibility Checker:** Check scholarship eligibility based on student details.
- **Scholarship Comparison:** Compare different scholarship opportunities.
- **Application Tracking:** Track scholarship application status.
- **Document Vault:** Manage important scholarship documents.
- **Saved Scholarships:** Save scholarships for future reference.
- **Student Dashboard:** Manage your scholarship activities in one place.

## 🛠️ Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- JavaScript

## 🚀 Getting Started

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone https://github.com/antim8799-prog/GRANTLYStudentScholarApp.git
```

**2. Open the project folder**

```bash
cd GRANTLYStudentScholarApp
```

**3. Install dependencies**

```bash
npm install
```

**4. Configure environment variables**

Create a `.env.local` file using `.env.example` as a reference and add the required values.

**5. Start the development server**

```bash
npm run dev
```

Open the local URL displayed in your terminal.
